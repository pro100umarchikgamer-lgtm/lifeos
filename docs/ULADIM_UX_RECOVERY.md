# ULADIM UX Recovery: рабочий checkpoint

База e12609e, ветка feature/uladim-ux-recovery-launch. Main не изменяется.

## Завершение задач

Старый выбор повторения исключал любые occurrence states, в том числе dismissed
и snoozed. Единственное уже закрытое/отложенное уведомление завершившейся серии
оставляло пустой список и вызывало occurrence_missing. Старые серии также терялись
за фиксированным окном 370 дней. Отдельно устаревшая revision из отрисованной строки
вызывала revision_conflict после записи из другого обработчика.

Новый выбор относится к последнему наступившему повторению и привязан к until
законченной серии. Уведомление не приравнивается к выполнению. Контроллер читает
persisted revision, использует storage CAS, объединяет одновременные нажатия,
поддерживает отмену/повторное выполнение. Операции журналируются в той же SQLCipher
базе. Ничего не удаляется и не мигрируется заново.

Android-регрессия воспроизводит запись 11 октября 09:00 Europe/Moscow, закрытие
и snooze уведомления, завершение 15 октября, stale revision, двойное нажатие,
настоящий Checkbox в Flutter, undo/re-complete и закрытие/открытие SQLCipher.
Календарные тесты включают старые серии, конец месяца, високосный день и IANA зоны.
Результат на устройстве пользователя ещё не подтверждён; итог CI фиксируется отдельно.

## Интерфейс и финансы

Today: раскрытый финансовый обзор первым, задачи со статусами, затем выбранные
заметки/модули. Сохранены видимость, порядок и настройки dashboard. Добавление —
через постоянный плюс, без повторяющихся огромных быстрых карточек на Today.
Финансы: реальные account balances, раздельные валюты, income/expense, интерактивные
дневные/недельные/месячные ряды, точные значения, категории с split allocations
и переход к исходной операции. BigInt используется для сумм; double только для
экранной геометрии. Переводы не считаются доходом/потреблением. Не привязанные
к счёту записи показывают net за период, не выдуманный банковский остаток.
Форма денег: настоящие счёт/категория открыты, декоративные подсказки-описания
не подменяют категории. Сохранение и заголовок остаются в EntrySheet.
Тёмный фон нейтральнее, контраст денежных акцентов повышен.

## Аккаунт и данные

Обычный пароль 7–256 символов; сервер блокирует распространённые, однообразные
и полностью цифровые варианты. Регистрация остаётся закрытой, rate limiting,
PBKDF2, session revocation и recovery не отключены. Backup-пароль остаётся от 12,
серверный ключ резервирования — от 32 байт. Обновлены все 16 пакетов, версия 12.
ApplicationId app.lifeos.lifeos, pin сертификата, UUID, миграции и форматы backup
сохранены. Модуля личных документов нет.

## Проверки и выпуск

Работа проходит focused Actions до полного CI. Старые проверки collapsed Today
заменены проверками явных сумм и финансового блока перед видимыми задачами.
Проверки клавиатуры, сохранения ввода, touch targets и overflow сохранены.
Снимки генерируются для ручного осмотра, не принимаются как доказательство
качества без просмотра. Финальные CI/APK ещё не выполнены на этом checkpoint.

Отдельный upgrade_probe использует только сохранённую APK 85001, создаёт
контрольные записи через её UI и проверяет update/restart без uninstall/data clear.
В финальном CI тот же сценарий получает единственную новую подписанную APK.
Прогон #90 остановился на несовместимом формате dumpsys UID; чтение UID исправлено
на стабильный cmd package list packages -U. Это сбой тестового инструмента,
а не подтверждение потери данных. Финальный результат будет зафиксирован отдельно.

VPS: HTTPS из Codespace отвечает Connection refused. Без доверенной консоли и
SSH-доступа отпечаток подтвердить невозможно. SMTP credentials/sender/allowlist
не предоставлены. Публичный запуск не объявлен; DNS менять не требуется.
