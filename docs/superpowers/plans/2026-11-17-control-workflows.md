## Global constraints

- No paid services or project restart; preserve active owner and existing functions/data.
- API authorization and identity checks are authoritative; no staff impersonation or private-record browsing.
- Use all16 shipped languages for new UI; user-entered content is not machine-translated.

## Review focus

- Different-account ticket never authorizes target recovery or leaks target data to its author.
- Restricted issuer cannot redeem/delegate authority it no longer has; pending sessions invalidate.
- Same-second/future registrations receive only the eligible welcome once; deleted users cannot reappear.
- Unsupported install browsers show honest guidance, while an accepted prompt is not mistaken for completed installation.
- Small screens, large text and pending actions preserve input and reachable controls; refresh keeps the requested section.
