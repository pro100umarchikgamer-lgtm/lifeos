# Personal Core — контрольные точки

База реализации: содержимое GitHub main `f13ad245`, сохранённое без удаления предыдущей локальной истории.

## 1. Изменение записей и миграция v2

Добавлены типизированные действия EditMoney/EditTask/EditNote/DeleteRecord/UndoRecordChange, проверка ревизии, мягкое удаление и история до/после изменения в той же транзакции с журналом операции. UUID/владелец/пространство/дата создания сохраняются. Изменения сумм не используют double и не меняют предполагаемый счёт.

Проверено локально: 15 Python тестов, включая обновление схемы v1, сохранность записей и операций, откат истории вместе с изменением и проверку ревизий. Добавлены Flutter domain и нативные integration тесты; запуск Flutter в текущей среде недоступен. Это не подтверждение работы SQLCipher на устройстве.

Ограничение среды: SDK Flutter отсутствует; запрос дополнительного сетевого доступа для SDK был прерван пользователем. Повторная установка не выполняется. Дальнейшая Flutter проверка должна выполняться в GitHub Actions.
