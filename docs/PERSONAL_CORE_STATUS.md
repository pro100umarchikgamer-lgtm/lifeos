# Personal Core — контрольные точки

База реализации: содержимое GitHub main `f13ad245`, сохранённое без удаления предыдущей локальной истории.

## 1. Изменение записей и миграция v2

Добавлены типизированные действия EditMoney/EditTask/EditNote/DeleteRecord/UndoRecordChange, проверка ревизии, мягкое удаление и история до/после изменения в той же транзакции с журналом операции. UUID/владелец/пространство/дата создания сохраняются. Изменения сумм не используют double и не меняют предполагаемый счёт.

Проверено локально: 15 Python тестов, включая обновление схемы v1, сохранность записей и операций, откат истории вместе с изменением и проверку ревизий. Добавлены Flutter domain и нативные integration тесты; запуск Flutter в текущей среде недоступен. Это не подтверждение работы SQLCipher на устройстве.

Ограничение среды: SDK Flutter отсутствует; запрос дополнительного сетевого доступа для SDK был прерван пользователем. Повторная установка не выполняется. Дальнейшая Flutter проверка должна выполняться в GitHub Actions.

## 2. Единое ядро календаря, копии и интеграция интерфейса

Реализация кандидата добавлена в рабочий проект:

- Схема v3: связанные календарные записи и состояния отдельных повторений с ревизиями. Изменение расписания и исходной записи атомарно, устаревшее расписание отвергается; отмена возвращает прежние состояния. История и UUID не очищаются.
- CalendarEngine: месяцы/дни, интервалы повторов, конец месяца/високосный год, конец серии, IANA-пояса, единая политика DST. Задачи и заметки используют этот же движок.
- UI: общая форма создания/редактирования, просмотр записи, мягкое удаление и отмена, календарь/повестка, выбор месяца/диапазона, одинаковая фильтрация сводки/списка, настройки. Сохранены палитра, карточки, иллюстрация и основная навигация; добавлены ограниченные анимации с учётом отключения движения.
- Android: AlarmManager, отдельные каналы, разрешения, recovery, durable outbox, snooze/dismiss/done, bounded foreground audio/vibration, открытие записи из уведомления. Служба учитывает блокировку уведомлений и настройки звука/вибрации канала. Нативные шаблоны версионируются в `tool/native/android` и копируются в генерируемую оболочку.
- Копия: AES-256-GCM, PBKDF2-SHA256/210000, случайные salt/nonce, аутентификация, ограничения размера, SAF и проверка повторного чтения. Криптография выполняется в isolate. Восстановление всей базы транзакционно после проверки схемы, идентичности, полей и внешних ключей. SQLCipher и ключ устройства сохраняются.
- Будущая синхронизация не реализована: остаются стабильные IDs, ревизии и typed operation journal. Сервер, банк, управление документами не добавлялись.

**Проверено локально:** 21 Python-тест и проверка RU/EN пакетов, `git diff --check`. Это проверка SQLite DDL/инвариантов и генерации конфигурации; она не исполняет Dart или Kotlin.

**Добавлено, но не выполнено:** Flutter unit/widget/visual тесты, integration-тест настоящей зашифрованной v1 базы → v3, проверка атомарного restore и Android bridge. Workflow запускает их, затем строит один финальный debug APK только при ручном `build_apk=true`. Push/PR автоматически APK не создают. Тестовый integration APK эмулятора используется для проверки и не публикуется.

**Приёмка не завершена:** Flutter/Dart/Android SDK отсутствуют; запись в GitHub через интеграцию запрещена (403). CI этого кандидата не запускался, PNG и APK не созданы; надёжность на реальном устройстве, производительность и визуальное соответствие не подтверждены. Контрольная точка сохраняется локально для продолжения, а не объявляется готовой к повседневному использованию.

15 языков/16 локалей остаются обязательным выпускным объёмом. Сейчас полными являются только RU/EN; остальные 14 пакетов и лингвистическая приёмка не выполнены. Будущие требования iOS/AI/обновлений сохранены в прежних документах и не реализованы.

Практический порядок проверки кандидата: `docs/ANDROID_PERSONAL_CORE_CHECKLIST.md`. Ограничения среды и последующие действия: `docs/ISSUES.md`.

Дополнительная проверка финансового риска: суммы аналитики и дневных корзин переведены на BigInt, потому что много допустимых больших записей могут переполнить signed 64-bit int. Форматирование целочисленное; double применяется только к высоте столбца, не к денежным значениям. Добавлены тесты суммы свыше 2^63 и её отображения. Попытка адресовать доход действием расхода (и наоборот) отклоняется.
