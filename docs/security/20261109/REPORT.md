существующий backend-suite; это не исчерпывающая проверка каждой комбинации
роли, метода, поля и состояния.

## Непроверенные условия выпуска

- SSH-ключ текущего Codespace зашифрован и не разблокирован. Попытка SSH получила Permission denied; защита не обходилась. Состояние контейнеров, миграций, мониторинга и бэкапов VPS в этом этапе заново не подтверждено.
- Первый владелец и фактическая MFA на VPS не подтверждены. Control должен остаться закрытым 503.
- Нет нового реального SMTP-цикла с двумя тестовыми почтовыми ящиками.
- Нет физического iPhone/iPad/Safari и Android APK: проверен общий HTTP-протокол, а не синхронизация реального телефона.
- Нет подтверждённого внешнего хранения бэкапов, восстановления production-копии в отдельную БД и отката на VPS в этом этапе.
- Нет полного аудита Git history/Actions/Codespaces/hPanel secrets, dependency/CVE сканирования и всех инфраструктурных портов.
- Полный редизайн ещё не внедрён: три интерактивные концепции ждут выбора владельца. Существующие 16 каталогов PWA сохранены; концепции демонстрируются по-русски.

## Порядок продолжения и отката

1. Владелец выбирает Clarity / Signal / Bloom; затем переносить систему компонентов по экранам, сохраняя текущие API и пользователей.
2. Разблокировать существующий SSH-ключ вне чата. Заново снять read-only инвентаризацию VPS и проверить резервную копию перед выпуском.
3. Развернуть проверенный security-коммит отдельно от большого редизайна; повторить HTTPS и авторизованную приёмку.
4. Откат — переключение на сохранённый предыдущий образ/release после проверки deploy-конфигурации. В этом этапе миграции не добавлены, данные и volumes не менялись. Команда отката на VPS пока не выполнялась.
5. Выполнить owner bootstrap/MFA с владельцем и только затем рассматривать открытие Control. Регистрацию и платежи сохранять закрытыми.
