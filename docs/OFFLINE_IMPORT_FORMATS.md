# Локальный импорт: подтверждённые границы

| Формат | Реализация | Проверки |
|---|---|---|
| CSV, TSV, TXT | Ограниченный текстовый парсер, UTF-8, UTF-16 с BOM, CP1251 | Разделители, кавычки, переносы, кириллица, точные суммы |
| JSON | Массив объектов; суммы строками либо целыми числами | Дробные JSON-числа отклоняются; точные строки сохраняются |
| OFX, QIF | Ограниченные записи операций, явная интерпретация дат | Нормализация дат и суммы |
| XLSX | Нативный ограниченный ZIP/XML-парсер | Android-тест: значения принимаются, формулы отклоняются |
| XML | Только схема statement/transaction/date/amount/description/currency | Android-тест: значения принимаются, DTD отклоняется |
| XLS, PDF | Не поддерживаются | Явный отказ; требуется экспорт в CSV |

Legacy XLS (OLE/BIFF) требует отдельного ограниченного парсера контейнера, строковых таблиц и продолжений записей, а также набора вредоносных и финансовых тестовых файлов. Добавлять непроверенный парсер в эту поставку небезопасно. Полная поддержка банковских форматов не заявляется. XLSX с формулами, макросами или внешними ссылками отклоняется, выполнение встроенного кода отсутствует.

Лимиты: файл 5 МБ, 10 000 операций, 100 столбцов, 4 000 символов в ячейке. Для XLSX дополнительно ограничены распакованный объём, количество ZIP-записей и время разбора. Исходный файл обрабатывается на устройстве и не сохраняется приложением. Совместимость с произвольными форматами каждого банка не подтверждена.
