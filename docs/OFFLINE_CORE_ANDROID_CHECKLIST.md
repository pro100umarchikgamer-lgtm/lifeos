# Приёмка Offline Core на Android

Выполнять только после успешного полного CI. Перед тестом иметь проверенную encrypted backup прежней установки. Не использовать реальные банковские данные в CI.

1. Проверить `applicationId=app.lifeos.lifeos`, SHA-256 сертификата против `ANDROID_TEST_CERT.sha256`, новый versionCode больше установленного. Установить поверх старого APK без удаления приложения; сохранить все старые UUID, деньги, заметки, задачи, календарь, темы и backup.
2. В авиарежиме создать/изменить/удалить/вернуть расходы и доходы. Расход без счёта не меняет остатки счетов. Назначить счёт задним числом и проверить остаток.
3. Перевести между двумя RUB счетами и RUB→USD с явно введённой полученной суммой. Изменить/удалить/вернуть; обе стороны согласованы, аналитика не считает перевод доходом/расходом.
4. Распределить расход 100 ₽ как 60+40 по категориям/проекту/профилю; изменить общую сумму вместе с частями; несходящаяся сумма отклоняется без потери данных. Проверить четыре политики переноса и отрицательный остаток.
5. Сохранить повторяющийся финансовый план: это не оплаченная операция. Подтвердить одну дату дважды — фактическая запись одна.
6. Добавить virtual earmark и отдельный вклад с явной ссылкой на перевод. Остатки денег не меняются дважды. Долг: principal/interest/fee отдельно; инвестиции: buy/sell/fee/dividend/valuation и отдельные realized/unrealized estimates.
7. Импортировать синтетические CSV, XLSX, OFX; проверить кодировку, разделитель, заголовок/лист, направление сумм, даты, валюту/счёт, ошибки строк и дубль. Выбрать подмножество; повтор не создаёт дубль. Отмена затрагивает только неизменённый пакет; изменённая запись останавливает отмену целиком. Отменить picker/preview: приложение не сохраняет выписку. XLS пока должен сообщать неподдерживаемый формат.
8. Создать проект/этап со сроком, связать канонические задачи/подзадачи. Сроки и связанные события видны в едином календаре. Циклическая подзадача отклоняется.
9. Привычка: check/uncheck из модуля и completion из календаря/уведомления. Проверить Europe/Berlin на DST, паузу/возобновление, отсутствие «пропусков» за паузу. Проверить историю после смены timezone.
10. Предмет/задание/повторяющееся расписание; заметка с тегами/ссылкой/чек-листом; покупки/шаблон домашних дел и новая копия; activity/sleep log. Перезапуск сохраняет связи.
11. Локальные профили с одинаковым именем: переименовать один, ID/ссылки сохраняются. Ребёнку нужен управляющий взрослый. Никакого фактического доступа с другого устройства или передачи личных данных нет.
12. Today: hide/show/reorder/compact/expanded; четыре Quick Add независимы. RU/EN, все прежние палитры/dynamic/light/dark; 320/390/430 dp, 200% text, keyboard и вложенный selector. «Повтор» не пересекает border, кнопки доступны.
13. Разрешения/диагностика: allowed/blocked, каналы со звуком/без, exact permission denied, test notification. Проверить три режима на физическом устройстве при заблокированном экране, reboot, timezone/time change, snooze/dismiss, OEM battery restrictions и DND. Факт невозможности точной/звуковой доставки должен объясняться.
14. Encrypted backup/restore на отдельной тестовой базе/устройстве: все новые таблицы/ссылки/журналы/настройки сохраняются. Wrong password/corrupt data/поддельная история Undo оставляют исходную базу целой. После restore напоминания согласованы с ОС.
15. Flutter profile mode: 1k/10k синтетических записей, DevTools frame/raster/CPU/memory при переходах, вводе, скролле и сохранении. Записать устройство/ОС/сборку, p50/p95 времени frames, jank и latency. Debug APK/PNG не подтверждают производительность.
