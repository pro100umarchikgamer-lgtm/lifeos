## Визуальная проверка утверждённого Home (2026-10-10)

- Причина: Flutter/Dart SDK отсутствует в текущем контейнере; одна попытка `git fetch` через настроенный прокси завершилась отказом соединения.
- Влияние: локально нельзя выполнить `flutter analyze`, widget тесты и снять скриншоты реального UI. Код и Python проверки доступны. Нельзя подтверждать визуальное соответствие или собирать APK до просмотра скриншотов.
- Попытки: проверена доступность SDK и выполнена одна ограниченная по времени попытка `git fetch`; повторная установка SDK не проводилась. Удалённые отличия сверены через GitHub API, небольшие исправления сохранены локально.
- Следующий шаг: запустить обновлённый GitHub Actions workflow, загрузить PNG для наполненного/пустого Home в светлой/тёмной темах при ширинах 390 и 320 dp; исправить ошибки анализа и отличия от утверждённого изображения. Workflow временно не строит APK.
- Публикация: GitHub API отверг создание blob с `403 Resource not accessible by integration` при первой попытке; прямой Git недоступен из-за прокси. Новые файлы и workflow сохранены в локальном проекте и передаются ZIP архивом. Для продолжения нужна GitHub авторизация с правом записи в `pro100umarchikgamer-lgtm/lifeos` либо ручная загрузка содержимого архива.

## Кириллица в golden-скриншотах после `c01ef10` (2026-10-10)

- Причина: стандартный шрифт Flutter widget tests не содержит кириллицы. В тестовый каталог добавлен Noto Sans и его лицензия; `visual_snapshot_test.dart` загружает шрифт до отрисовки. Рабочие UI-виджеты и тема не изменены.
- Влияние: новые скриншоты нельзя считать проверенными, пока workflow не запустится и артефакт не будет просмотрен. `tool/verify_goldens.py` проверяет наличие и размеры всех 14 PNG; golden тесты проверяют ошибки layout.
- Попытки: прямой Git через прокси и GitHub API для создания blob не работают (`403 Resource not accessible by integration`); обход прокси также не дал соединения. Локального Flutter SDK нет. Повторять этот блокер в текущей среде не следует.
- Следующий шаг: предоставить рабочий канал записи в репозиторий или загрузить подготовленный архив, запустить Stage 1 workflow, просмотреть 14 PNG с читаемой кириллицей и исправить выявленные переполнения до сборки APK.

## Offline Core C — ограничения и непроверенные проверки (2026-10-11)

- **XLS (старый BIFF/OLE) и произвольные PDF**: безопасного адаптера в проекте нет. Не установлены непроверенные парсеры и не выполняются макросы/формулы. XLS пока отклоняется; следующий шаг — отдельный ограниченный BIFF/OLE адаптер с реальными банковскими fixtures. PDF допускается спецификацией только при надёжном парсинге; сейчас не поддерживается, предлагается экспорт CSV. Пакет C поэтому не объявляется полностью завершённым.
- **Dart/Flutter и Android XLSX/XML**: SDK отсутствует; выполнены проверки схемы Python и подготовлены Dart-тесты, но это не подтверждает работу UI, SAF или native-парсера. Следующий шаг — полная CI с Kotlin/Flutter и импортом fixtures на Android. Установки SDK не повторялись.
- XML имеет явную схему `<statement><transaction><date>YYYY-MM-DD</date><amount>-12.50</amount><description>…</description><currency>RUB</currency></transaction></statement>`. Неподдерживаемые схемы отклоняются. XLSX листы показываются по техническому имени sheetN; даты Excel требуют явного выбора формата. Источник только в оперативной памяти, не в резервной копии.
