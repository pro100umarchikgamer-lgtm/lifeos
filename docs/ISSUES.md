# Нерешённые вопросы этапа 1

| ID | Причина и влияние | Попытки | Следующее действие |
|---|---|---|---|
| ENV-01 | Нет Flutter/Dart SDK; недоступны анализ, Flutter-тесты, форматирование и сборка | Проверены команды/пути. Запрос SDK ожидал разрешения и был прерван; запрос без дополнительных прав отказал на proxy; установка из GitHub снова ожидала разрешения и была прервана. Лимит сетевых попыток исчерпан | Среда с установленным Flutter и доступом к pub.dev. Больше не настраивать сеть в этой сессии |
| ENV-02 | Нет Android SDK и устройства; шифрование, плагины, перезапуск и UI не проверены нативно | Отсутствие инструментов установлено; установка пропущена из-за ENV-01 | Создать оболочку скриптом, debug-сборка и интеграционный тест на устройстве без сети |
| DEP-01 | Совместимость SQLCipher/secure storage не проверена через pub; lock-файл отсутствует | Подобраны ограничения версий; сетевых повторов не делали | `flutter pub get`, сохранить lock и SDK; исправить фактические несовместимости без обхода шифрования |
| LOC-01 | Текущие экраны переведены на RU/EN; остальные 14 локалей ещё не подготовлены | Сохранён перечень 15 языков/16 локалей; выпускная проверка отклоняет неполный набор | Полные пакеты и лингвистическая проверка к этапу 7. Для языков без Material-переводов заменить английские системные строки |
| IOS-01 | Оболочка, keychain/backup и оповещения iOS не проверены; поддержка iOS не заявляется | Общее ядро и генерация оболочки подготовлены; нативные проверки пропущены | macOS, Xcode и iPhone при начале поддержки iOS |
| GH-01 | Репозиторий `pro100umarchikgamer-lgtm/lifeos` отсутствует; публикация кода и запуск Actions/APK пока невозможны | GitHub connector подтвердил логин и ответил 404 для репозитория; у доступного connector нет операции создания репозитория. `gh auth status` показал недействительный `GH_TOKEN`. Не предпринимались повторные сетевые попытки | Обновить GitHub-доступ для CLI с правами на создание приватного репозитория и загрузку workflow (для classic PAT: `repo` и `workflow`) **через защищённую настройку, не присылая токен в чат**; либо создать приватный `lifeos` с начальным README в GitHub и дать connector запись. Затем отправить сохранённый локальный коммит |
| CI-01 | Workflow добавлен, но не выполнен; статус сборки и доступность APK неизвестны | Настройка файла и локальная проверка структуры; запуск невозможен до GH-01 | После push открыть Actions, дождаться `Stage 1 checks and debug APK`, скачать артефакт `lifeos-debug-apk-N`; исправлять конкретную ошибку не более трёх попыток |

ENV-01/02 требуют другой среды, а не более сильной модели. Проверка нативных API и зависимостей требует запуска. Эти проблемы не оправдывают удаление базы, открытое хранение вместо SQLCipher или переход к этапу 2 без приёмки первого.
