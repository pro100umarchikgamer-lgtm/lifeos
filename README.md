# LifeOS — этап 1

Автономное ядро Flutter: быстрый ввод расхода, дохода, задачи и заметки, личная зашифрованная база, навигация для телефона/планшета, светлое и тёмное оформление, версионированные языковые пакеты.

**Статус:** исходники подготовлены; приёмка Flutter и устройства заблокирована отсутствием SDK. Не считать этап завершённым до выполнения проверок ниже. Подробнее: [отчёт](docs/STAGE_1.md), [открытые вопросы](docs/ISSUES.md).

## Запуск в среде с Flutter

```sh
bash tool/prepare_platforms.sh
flutter pub get
dart format lib test integration_test
flutter analyze
flutter test
flutter run
```

Скрипт создаёт только отсутствующие системные оболочки стандартным генератором Flutter, не заменяет бизнес-код и применяет настройки приватности Android. После успешного разрешения зависимостей нужно сохранить `pubspec.lock`. Сборка для выпуска пока не готовится.

GitHub Actions на каждый push, pull request или ручной запуск выполняет Python-проверки, получает Flutter, разрешает зависимости, запускает анализ и Flutter-тесты, собирает отладочный Android APK. При успешной сборке APK доступен в артефакте `lifeos-debug-apk-N` соответствующего запуска в разделе Actions. До первого успешного запуска наличие APK не подтверждено.

## Проверки

```sh
python3 -m unittest discover -s tool/tests -v
python3 tool/validate_packs.py
flutter test
flutter test integration_test/offline_storage_test.dart -d DEVICE_ID
flutter build apk --debug
```

Интеграционный тест использует отдельную тестовую базу и ключ; данные обычного профиля не удаляет. Он проверяет реальное шифрование, повтор операций, восстановление после открытия и отказ при потере ключа. Выполнить на Android-устройстве без сети. Python-проверки проверяют SQL-схему и пакеты, но не заменяют Flutter, SQLCipher и устройство.

## Локализация

В первом этапе полные пакеты текущих экранов: английский и русский. Целевой перечень в `tool/launch_locales.json`: 15 языков, 16 локалей с узбекской латиницей и кириллицей. Остальные переводы и лингвистическая проверка входят в этап завершения v0.1.

Добавление полного `assets/locales/LOCALE.json` автоматически включает язык в интерфейс. `python3 tool/validate_packs.py --release` запрещает выпуск без всех локалей запуска. Проверяются версия схемы/пакета, ключи, параметры и формы множественного числа.

## Границы

Нет регистрации, облачных запросов, банковских подключений или управления документами. Backend пока не подключён; Supabase остаётся заменяемым кандидатом. Будильники реализуются нативно на этапе 4; таймеров Dart для доставки нет.
