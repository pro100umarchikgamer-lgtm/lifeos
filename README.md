# LifeOS — личное и семейное пространство

Android-first Flutter-приложение: финансы, планы, заметки, календарь и персональные модули. Личные данные остаются в SQLCipher на устройстве. Семейная синхронизация включается по желанию; общие и личные записи изолированы, неотправленные изменения сохраняются в зашифрованной очереди.

Ветка `feature/lifeos-3-production` продолжает проверенную реализацию `8b648797`. `main` не переписывается. Версия кандидата — `0.3.0`. Это приложение для тестирования и подготовленный backend, а не объявление публичного сервиса.

## Backend

PostgreSQL с проверяемыми миграциями, регистрацией и подтверждением почты, восстановлением аккаунта, ограниченными сессиями, серверными правами семьи и согласованием прав родителей. UUID, денежные значения, история и подтверждения операций сохраняются. Синхронизация поддерживает пакетный push, инкрементальные страницы, повтор операций, конфликты и обновление общего кэша после изменения доступа.

Docker Compose запускает базу, миграции, API, SMTP-очередь и Caddy с HTTPS. Предусмотрены health checks, локальный мониторинг, шифрованные резервные копии и восстановление в новую базу без перезаписи действующей. Инструкция: [PRODUCTION_BACKEND.md](docs/PRODUCTION_BACKEND.md). Домен, VPS и почтовый провайдер здесь не куплены и не развёрнуты.

## Интерфейс

Светлые и тёмные темы, адаптивные ввод и навигация, приветствие и аккаунт без ручного ввода сервера, семейное пространство, приглашения и наборы детских прав. Сохранены быстрые действия, выбор Grid/List, поиск по пространству, предварительный просмотр банковского импорта и обычный ввод валютных сумм. Сырые выписки не отправляются на сервер автоматически.

## Разработка и проверка

Используйте поддерживаемую изолированную среду с Flutter SDK. Не запускайте Flutter в среде, где его определение CI обращается к запрещённым служебным метаданным.

```bash
bash tool/prepare_platforms.sh
flutter pub get
flutter analyze
flutter test
python -m pip install -r backend/requirements.txt
python -m unittest discover -s backend/tests -v
PYTHONPATH=. python tool/check_sync_protocol.py
```

Без PostgreSQL пропускаются только отдельно обозначенные PostgreSQL-тесты. CI поднимает реальную тестовую PostgreSQL 17 с ролью без административных прав, проверяет два Dart-клиента, полный Compose, миграцию старого серверного SQLite и backup/restore. Финальный workflow дополнительно выполняет анализ Flutter, Dart/widget/визуальные проверки, Kotlin compilation и SQLCipher/двухклиентную интеграцию на Android.

## Тестовый APK

В Actions выберите эту feature-ветку. Для текущих изменений используйте focused checks; после их приёмки выполните один полный запуск с обязательной проверкой всех шагов и флагом сборки APK. Сборка сохраняет `app.lifeos.lifeos`, проверяет прежний сертификат из [ANDROID_TEST_CERT.sha256](docs/ANDROID_TEST_CERT.sha256) и повышает versionCode, позволяя обновление без удаления данных.

После развёртывания и проверки своего backend задайте repository variable `LIFEOS_API_ORIGIN` как HTTPS origin без логина, пути и query. CI передаёт его в приложение при сборке. Пока origin не задан, новая установка работает локально и показывает, что семейное подключение ещё не настроено. Существующий сохранённый аккаунт сохраняет свой origin и очередь; данные не переносятся молча на другой сервер.

Исторические отчёты находятся в `docs/`; их статусы относятся к соответствующим прежним этапам.
